### معرفی
این مخزن مسیر یادگیری عمیق علوم کامپیوتر من است.  
هدف اصلی این پروژه:
**رشد ذهن مهندسی، تمرین الگوریتم، ساخت پروژه واقعی و ثبت مسیر یادگیری**.

### ساختار پوشه‌ها
- `notes/` : یادداشت‌ها و نکات آموزشی
- `problems/` : مسائل الگوریتمی و حل آنها
- `projects/` : پروژه‌های عملی
- `reports/` : گزارش‌های دوره‌ای، Markdown، یا یادداشت پیشرفت
- `english/` : تمرین و یادگیری زبان انگلیسی مرتبط با برنامه‌نویسی

### روش کار
- هر تغییر مهم را commit و push کن
- تغییرات بزرگ روی branch جداگانه → Pull Request → merge
- مسیر باید پایدار باشد: تمرکز روزانه حدود ۴–۵ ساعت
- تمرین زبان انگلیسی روزانه نیم ساعت

## 🇺🇸 English

### Overview
This repository is my **CS learning journey**.  
Main goals: **develop engineering mindset, practice algorithms, build real projects, and track learning progress**.

### Folder structure
- `notes/` : study notes and observations
- `problems/` : algorithm problems and solutions
- `projects/` : practical projects (e.g., Planer)
- `reports/` : bi-weekly reports, Markdown, or progress notes
- `english/` : focused English learning related to programming

### Workflow
- Commit & push every important change
- Large changes → separate branch → Pull Request → merge
- Keep the workflow sustainable: daily deep focus ~4–5 hours
- Daily English practice: ~30 minutes

---

> **Tip:** Keep your repository clean and organized. Use branches for new features and PRs for merging. This ensures a professional, maintainable workflow.
